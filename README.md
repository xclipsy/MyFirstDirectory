# 🧾 Sistema de Facturación en Python

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)
![Estado](https://img.shields.io/badge/Estado-Funcional-brightgreen)
![Licencia](https://img.shields.io/badge/Licencia-Educativa-orange)

Aplicación de consola desarrollada en **Python** que permite generar una factura de venta de forma interactiva.  
El sistema calcula automáticamente subtotal, IVA (16%), descuento por membresía (10%) y total a pagar.

---

## 📌 Características

- ✅ Registro del nombre del cliente  
- ✅ Ingreso dinámico de múltiples productos  
- ✅ Cálculo automático de subtotal  
- ✅ Cálculo de IVA (16%)  
- ✅ Descuento del 10% para clientes con membresía  
- ✅ Factura formateada en consola  
- ✅ Validación básica de respuestas  

---

## 🛠 Tecnologías Utilizadas

- 🐍 Python 3  
- Listas  
- Funciones  
- Bucles `while`  
- Manejo básico de excepciones
